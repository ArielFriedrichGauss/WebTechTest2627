# Design reference

USTFood should feel like a USThing product, not a generic food app.

## Live reference

- Dashboard: [app.usthing.xyz](https://app.usthing.xyz)
- Primary colour from the brief: `#003366`

This starter copies dashboard tokens and a simplified sidebar. You do not need to clone every dashboard screen. Match density, type, colour, and navigation language.

| Token | Light | Dark |

| Page background (`base-100`) | `#F6F6F6` | `#121212` |

| Sidebar (`neutral`) | `#FFFFFF` | `#1F1F1F` |

Typeface: **Poppins**, same as the dashboard.

## What “matching USThing” usually means

- Calm academic product, not a delivery-app look
- Navy as the main action colour; yellow used sparingly
- Rounded cards, light borders, generous spacing
- Sidebar + main canvas on desktop; compact header on mobile
- Light and dark both usable

## What you should still decide

Layout of discovery, how comparison works, how detail and reviews appear, empty/error states, and any extra features. Visual polish is part of the grade.
